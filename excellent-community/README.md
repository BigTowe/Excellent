# Excellent Community — персональный сайт-портфолио

Готовый сайт для команды **Excellent Community** (@secoxyde).
Чистый HTML/CSS/JS — без сборки, без зависимостей, работает везде.

## 🚀 Как открыть

Просто открой файл `index.html` двойным кликом в браузере — всё работает.

Для «взрослого» запуска залей папку на любой бесплатный хостинг:
- **GitHub Pages** — создай репозиторий, загрузи файлы, включи Pages в настройках
- **Netlify Drop** — перетащи папку на https://app.netlify.com/drop
- **Vercel** — `vercel deploy` или через сайт
- **Cloudflare Pages** — тоже бесплатно

## ⚙️ Как настраивать

### Способ 1 — панель настройки (проще всего)
1. Открой сайт в браузере.
2. Нажми **Ctrl + Shift + A** (или кнопку ⚙ в правом нижнем углу).
3. Меняй тексты, работы, услуги, цены, цвета — сайт обновляется сразу.
4. Нажми **«⬇ Скачать config.js»** и замени им старый файл в папке сайта —
   правки станут постоянными.

Правки хранятся в браузере (localStorage), пока не скачаешь новый config.js.

### Способ 2 — правка config.js
Открой `config.js` в любом блокноте (лучше VS Code). Там всё подписано
по-русски: бренд, услуги, портфолио, цены, FAQ, тексты формы.

Чтобы **добавить работу** — скопируй блок `{...}` в `portfolio.items`
и вставь в конец списка (не забудь запятую между блоками).

Картинки работ клади в `assets/img/` и указывай путь:
```js
image: "assets/img/my-project.jpg"
```
Если `image: ""` — карточка рисуется красивым градиентом с инициалами.

## 📬 Как работает форма заказа

Форма не требует сервера: посетитель заполняет поля → сайт формирует
готовое сообщение и копирует его в буфер обмена → кнопка открывает
Telegram, остаётся вставить и отправить тебе в @secoxyde.

Если захочешь получать заявки автоматически (на почту/в базу) — впиши
URL любого сервиса форм (Formspree, Getform, свой бэкенд) в
`order.webhook` в config.js, и заявки будут дублироваться туда.

## 📁 Структура

```
excellent-community/
├── index.html      — разметка сайта
├── styles.css      — стили (цвета меняются в config.js → theme)
├── app.js          — логика: рендер, форма, панель настройки
├── config.js       — ⭐ ВСЕ НАСТРОЙКИ САЙТА (главный файл)
├── README.md       — эта инструкция
└── assets/
    └── img/        — картинки работ и favicon
```

## 🎨 Быстрая смена цветов

В `config.js` → раздел `theme`:
```js
theme: {
  accent: "#7C5CFF",     // основной цвет (фиолетовый)
  accent2: "#22D3EE",    // второй цвет градиента (циан)
  background: "#06060A"  // фон
}
```
Или используй палитру цветов прямо в панели настройки.
